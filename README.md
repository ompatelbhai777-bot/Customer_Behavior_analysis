# Customer_Behavior_analysis
Data analysis showcasing Customer_Behavior_analysis using Python,Sql,Excel, PowerBI

Project Overview

This project demonstrates an end-to-end Data Analytics workflow using Python, PostgreSQL, SQL, and Power BI.

The main objective is to analyze the dataset, identify useful business insights, and present the findings through an interactive dashboard.

 Tools Used
Python
Pandas
NumPy
Matplotlib
Seaborn
PostgreSQL
SQL
Power BI
🔄 Project Workflow

1. Data Loading → 2. EDA → 3. Data Cleaning → 4. SQL Analysis → 5. Power BI Dashboard → 6. Final Report

1. Data Loading

The dataset was loaded into Python using Pandas and inspected to understand its structure, columns, data types, and size.

2. Exploratory Data Analysis

EDA was performed to identify:

Missing values
Duplicate records
Outliers
Data distributions
Important patterns and relationships

Python visualizations were used to understand the data.

3. Data Cleaning

The data was cleaned by:

Handling missing values
Removing duplicates
Correcting data types
Standardizing values
Handling invalid records
Preparing the final dataset for analysis
4. PostgreSQL & SQL Analysis

The cleaned data was imported into PostgreSQL.

SQL queries were used to analyze:

Revenue
Orders
Customers
Products
Categories
Payment methods
Order status
Monthly trends
5. Power BI Dashboard

The cleaned data was connected to Power BI and an interactive dashboard was created.

The dashboard includes:

KPI Cards
Revenue Analysis
Order Analysis
Customer Analysis
Product Analysis
Category Analysis
Payment Analysis




Interactive Filters/Slicers
6. Final Report

The final report summarizes the analysis, key findings, business insights, and recommendations.

 Key Outcomes

The project provides insights into:

Overall business performance
Top-performing products and categories
Customer purchasing behavior
Revenue trends
Payment preferences
Order performance

 Conclusion

This project demonstrates the complete Data Analyst workflow, from raw data preparation to SQL analysis and Power BI visualization.

It showcases practical skills in Python, SQL, PostgreSQL, Power BI, data cleaning, EDA, and business analysis.
